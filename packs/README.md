# Character pack zip files

These zip packs are [Release assets](https://github.com/Intense-Finance/Grobie/releases/tag/v1.0.0) and are also published at [https://grobie.slopcore.army/](https://grobie.slopcore.army/). Each file is larger than 50 MB, so they are not stored in the git tree. The same stills, audio, and docs are already unpacked under [`../character/`](../character/).

The v1.0.0 packs were rebuilt with the current tools, including `assemble_dc_v2.py` and `lipsync_mouthmask_v4.py`.
