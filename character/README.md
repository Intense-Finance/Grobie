# Grobie character kit

This folder is the open Grobie character kit, dedicated as CC0 1.0 Universal. See [LICENSE.txt](LICENSE.txt). Please keep Grobie PG-13 (a request, not a license condition).

Layout matches [https://grobie.slopcore.army/](https://grobie.slopcore.army/), so the paths in the root [`character.json`](../character.json) stay valid:

- `CHARACTER-BIBLE.md` — who Grobie is (MAIN BOT, Admiral, Main Teammate, ☯️) and the production rules
- `VIDEO-KIT.md` — how to use the video kit
- `grobie-*.jpg` — earlier stills, **non-canonical for video**
- `v2-video-kit/` — Master Character Sheet v2, six canonical locks, 4K PNG masters, mouth shapes, approved voice clips, WARP978 v2 lyrics and cue sheet

Start with `v2-video-kit/grobie-character-sheet-v2.jpg` (and the 4K PNG). Use the JPEGs for everyday reference and the 4K PNGs when a tool accepts a large still. Prefer WAV clips for lip-sync; MP3 is for compact playback.

The large zip packs (`grobie-piper-video-kit.zip` and `grobie-full-archive.zip`) are planned GitHub Release assets, not stored in git. See [`../packs/`](../packs/) and the same files on the live site:

- https://grobie.slopcore.army/packs/grobie-piper-video-kit.zip
- https://grobie.slopcore.army/packs/grobie-full-archive.zip
